# 主升初期识别算法设计

## 1. 目标与准确率的定义

**一个"成功的主升周期"**(训练标签、回测、APP 统一使用):

> 信号日收盘发出 → **次日开盘价买入** → 之后允许回撤,但**收盘价**跌破 买入价 × (1 − 15%) 即判失败(`label.maxDrawdown`,设 0 表示回撤不限)
> → 在 60 个交易日内(`label.horizon`),**某日收盘价相对买入价扣除成本后盈利 ≥ 30%**(`label.target`),即为成功。

要点:
- 不要求"直接涨",中途回撤多少都可以,只要收盘没跌破容忍线;
- 全部按**收盘价**判断,盘中最低价跌得再深也不算(对应"截止收盘整体盈利");
- 成本(默认单笔往返 0.3%,`backtest.cost`)已扣除,"30%"是净利润;
- 等价于用"收盘达 +30% 止盈 / 收盘回撤 15% 止损 / 最多持有 60 日"做一次交易,看这个周期是否净赚 30%。

**准确率** = 已完成的交易周期中,按选定卖出规则卖出时(收盘价)扣成本盈利 ≥ 30% 的比例。
- 同一只股票 20 个交易日内只算第一次信号(同一波启动不重复计数);
- 数据末尾还没卖出的周期列为"未完成",不计入;
- 买入日买不进(一字涨停)的信号单独统计。

**需要提前知道的事实:**
- 在 A 股真实数据上,满足候选条件的"启动日"里,事后真正走出 +30% 的只占一小部分(训练日志会打印这个"基准成功率")。模型要把它提升到 95%,只能把阈值提得很高,信号会变少。
- 信号太少时 95% 没有统计意义:10 个信号中 10 个成功,真实准确率的 95% 置信下限只有约 72%。所以程序同时要求测试期已完成信号数 ≥ `target.minTestSignals`,并在报告里给出 Wilson 置信下限。
- 阈值、卖出规则、早停轮数都只在验证期选;测试期从未参与任何选择,只用来检验。达不到就如实标记"未达标"(文件名带 `-NOT-PASSED`,`passed=false`),APP 应醒目提示。
- 达不到 95% 时可以调整的杠杆(都是"信号数量"与"准确率"的取舍):收紧 `gate.*`;放宽 `label.maxDrawdown` 或拉长 `label.horizon`;降低 `label.target`。每次调整后重训,不要反复盯着同一段测试期调参。

## 2. 整体流程

```
通达信离线日K ─┬─ vipdoc/*.day(不复权,启发式除权)
               └─ 导出 txt(前复权,GBK 自动识别)
通达信 hq_cache(可选,通常就在 vipdoc 旁边)── tdxhy.cfg 行业 / block_gn.dat 概念
        │
        ▼
① 全市场预扫描(读一遍所有股票)
   ├─ 市场情绪:涨停/跌停家数、炸板率、连板高度、晋级率、涨停溢价、赚钱效应……
   ├─ 板块:通达信行业;没有 hq_cache 时按收益相关性聚类(每年重算,无未来函数)
   └─ 板块/概念强度、个股板块内排名
        │
        ▼
② 候选"启动日"(硬条件) → ③ 99 个特征 → ④ 标签(第 1 节的定义)
        │
        ▼
⑤ 时间切分:训练 | 验证 | 测试(按时间;训练样本的标签周期不得伸入验证期)
        │
        ▼
⑥ GBDT 梯度提升树(按交易日平衡权重、AUC 早停、特征组筛选)
        │
        ▼
⑦ 一次扫描验证期 + 测试期:每个候选信号在 76 组卖出规则下的结果
        │
        ▼
⑧ 验证期同时选 卖出规则 + 各启动类型的概率阈值
        │
        ▼
⑨ 测试期按年滚动重训检验 → 达标判定 → 用全部数据重训导出 model-*.json + report.md
```

### 2.1 候选启动日(硬条件)

| 条件 | 默认值 | 作用 |
|---|---|---|
| 上市满 | 120 个交易日 | 剔除次新股阶段 |
| 5 日均成交额 ≥ | 3000 万 | 剔除流动性差、易被操纵的标的 |
| 当日涨幅 ≥ 3% 或 量比 ≥ 1.8(且收涨) | | 有启动动作 |
| 启动前 20 日涨幅 ≤ | 25% | 只要"初期",已经涨多的不要 |
| 当日收阳 / 剔除 ST / 复牌 5 日内不发信号 | | 过滤噪声 |

### 2.2 三类主升启动(标注,用于分类统计)

| 类型 | 判定 |
|---|---|
| 箱体突破 | 前 60 日振幅 ≤ 35% 且突破前 60 日最高价,或前 30 日振幅 ≤ 20% 且突破 |
| 超跌反弹 | 距 250 日高点回撤 ≥ 30%,且 60 日跌幅 ≥ 10% 或近 10 日 RSI6 曾 ≤ 20 |
| 趋势波段 | MA60 向上、价在 MA60 上方、均线多头排列度 ≥ 2 |

| 趋势位置 | 12 | 60/250 日区间位置、距高点回撤/距低点涨幅、偏离 MA5/20/60/120、均线斜率、多头排列度、均线粘合度 |
| 形态指标 | 17 | 30/60 日箱体振幅与突破幅度、布林 %b/带宽/收口变化、MACD、KDJ-J、RSI、ATR、波动率 |

| 资金 | 5 | K 线估算主力净额(CLV 资金流,当日/5 日/20 日);大单净量(外部数据,通常为空) |

| **筹码分布** | 7 | 获利盘比例、收盘偏离平均成本、90%/70% 筹码集中度、上方 10% 内套牢盘、下方 10% 内支撑筹码、获利盘 5 日变化 |

### 3.1 市场情绪(只用 vipdoc 就能算)

预扫描时把每只股票对齐到交易日历,逐日统计:
- **涨停/跌停**:收盘涨跌幅达到该股当日涨跌停幅度(主板 10%、创业板 2020-08-24 后 20%、科创板 20%、北交所 30%,前复权误差留 0.3% 容差;新股前 5 日不算);
- **炸板**:盘中最高价触及涨停但收盘没封住;炸板率 = 炸板 / (涨停 + 炸板);
- **连板高度**:当日所有涨停股中最大的连续涨停天数;
- **连板晋级率**:昨日涨停股今日继续涨停的比例;**涨停溢价**:昨日涨停股今日平均涨幅(接力情绪的核心指标);
- 赚钱效应:上涨家数占比、站上 MA20 占比、创 60 日新高占比。

> 没有股票名称时(.day 文件不含名称)无法识别 ST,ST 股的 5% 涨停不计入涨停家数;提供 `data.namesCsv` 或用 txt 导出可修正。

### 3.2 板块:三种来源

| 来源 | 什么时候用 | 说明 |
|---|---|---|
| 通达信行业 | 找到 `T0002/hq_cache/tdxhy.cfg`(通达信客户端自带,vipdoc 在 `通达信目录\vipdoc`,hq_cache 在 `通达信目录\T0002\hq_cache`) | 默认二级行业,`sector.industryLevel` 可调 |
| 收益相关性聚类 | **只有 vipdoc** 时自动使用 | 每个自然年初,用之前 250 个交易日的日收益,对全市场做球面 k-means(余弦相似度)聚成 40 组(`sector.clusters`)。走势高度同步的股票分到一组,通常就是同一行业或同一题材。第 Y 年的分组只用 Y 年之前的数据,没有未来函数 |
| 通达信概念 | 找到 `hq_cache/block_gn.dat` | 多归属;**成分是当前名单**,历史回测有"事后归入概念"的未来函数,会偏乐观。可设 `sector.useConcepts=false` 再训练一次对比 |

板块指数 = 成员股等权日收益累乘(单日收益截断在 ±35%,防止除权缺口干扰)。

### 3.3 筹码分布(日 K 近似,与通达信 CYQ 同原理)

每天:旧筹码按换手率 τ 衰减(× (1−τ)),当天成交的 τ 份筹码按三角分布摊到 [最低价, 最高价],峰值在 (高+低+2×收)/4。
- 没有流通股本时 τ = 2% × 当日量 / 近 250 日均量(相对换手);提供 `data.floatSharesCsv` 时用真实换手率;
- 价格网格为固定的对数刻度(每格 1%),与数据从哪天开始无关;
- 由分布得到:获利盘(成本低于收盘价的筹码比例)、平均成本、90%/70% 集中度 = (高分位−低分位)/(高分位+低分位)、上方 10% 套牢盘、下方 10% 支撑筹码。

### 3.4 大单净量

通达信离线日线(.day)只有开高低收量额,**不含逐笔/大单数据**,只用 vipdoc 无法得到真实的大单净量。程序用 CLV 资金流估算主力净额作替代:成交额 × [(收−低) − (高−收)] / (高−低),收盘越靠近最高价,买方越主动。如以后有 Level-2 数据,按 `代码,日期,大单净量%` 导出给 `data.bigOrderCsv` 即可启用。

### 3.5 还可以继续加的(本版未实现)

北向/融资余额变化、财务数据(业绩预告、ROE)、龙虎榜。新增特征:在 `FeatureDefs.ALL` 末尾追加 → `FeatureEngine.compute` 中计算 → **`FeatureDefs.VERSION` 加 1** → 重训。

## 4. 模型:GBDT 梯度提升树

纯 Kotlin 实现(`trainer/GbdtTrainer.kt`):直方图算法(每特征 ≤64 箱、1 字节存储)、叶子优先生长(≤15 叶、深度 ≤5)、L2 正则、行/列采样、缺失值自动选择分裂方向。导出阈值即分箱边界的 float 值,APP 端推理与训练端逐位一致(单元测试校验)。训练过程可复现。

### 4.1 防止"记住行情阶段"(第一次真实数据训练暴露的问题)

第一次用真实数据训练:验证 AUC 只有 0.52,特征重要性里市场情绪 + 市场环境占 71%。这两组特征对同一天的所有股票取值相同,模型实际学到的是"2010–2019 年哪些时间段是牛市"(例如 2015 年几千个候选全部成功),换到 2020 年以后就不成立。对策:

| 措施 | 说明 |
|---|---|
| 按交易日平衡样本权重 | 权重 ∝ 1/√(当日候选数),火爆交易日不再以样本数量压倒其他日子(`gbdt.dateBalance`) |
| 早停用 AUC | logloss 会被"验证期整体成功率与训练期不同"干扰,AUC 只看排序(`gbdt.earlyStopMetric=auc`) |
| 更强正则 | 叶子 31→15、最小叶子样本 200→500、L2 1→5、列采样 0.8→0.6、学习率 0.05→0.03 |
| 特征组自动筛选 | 分别训练"全部特征""去掉全市场类""再去掉概念",按验证 AUC 选优;报告列出对比(`gbdt.groupSelect`) |

### 4.2 每种启动类型单独选阈值

报告显示超跌反弹的成功率(测试期 54.9%)远高于箱体突破(28.1%)。统一阈值会让好类型的信号被挤掉、差类型的信号混进来。现在每种类型各自选阈值;达到目标的类型才启用。都达不到时,每种类型取 **95% 置信下限最高** 的阈值,再按下限从高到低逐个加入、只要整体下限还在提高 —— 不会再为了凑信号数选出上万个低质量信号。合并后再逐类核对,不达标的提高阈值或停用。

### 4.3 滚动重训与最终重训

- **测试期按年滚动重训**:每年年初用此前全部已有标签的样本重训一个模型,检验当年。不同模型的概率刻度不同,阈值按"验证期选中的分位数"迁移(在新模型上一年的候选中取同样比例)。
- **导出模型用全部数据重训**:以前导出的是只见过训练期(例如 2019 年以前)数据的模型;现在用到最新交易日的全部样本重训,阈值同样按最近一年候选的分位数迁移。

## 5. 卖出规则

全部**按收盘价判断、按收盘价成交**(尾盘卖出):

```
容忍回撤: 收盘 ≤ 买入价×(1−stopLoss) → 卖出(0 = 不设)
固定止盈: 收盘 ≥ 买入价×(1+takeProfit) → 卖出
动态止盈: 最高收盘 ≥ 买入价×(1+激活线) 后,收盘 ≤ 最高收盘×(1−回撤) → 卖出
          可选"利润保护":激活后收盘跌回 买入价×(1+profitFloor) 也卖
到期:     持有满 N 日按收盘卖出
```
T+1:买入当天不能卖;一字跌停卖不出,顺延;一字涨停买不进,信号作废。

验证期从 76 组规则中与阈值**一起**选(`exit.gridSearch=true`):固定止盈 30% 与动态止盈(激活线 30/40/50% × 回撤 10/15/20% × 是否锁定 30% 利润),各配 4 档容忍回撤(10/15/20%/不设)。
- `exit.objective=precision`(默认):准确率达标前提下信号最多 —— 通常选中"收盘达 +30% 即卖",因为它直接对应"一个周期净赚 30%";
- `exit.objective=return`:准确率达标前提下平均收益最高 —— 通常选中动态止盈,让利润奔跑,但回落卖出时可能低于 30%。
报告列出同一阈值下各规则在验证期与测试期的准确率和平均收益,方便比较。

## 6. 检验

- **时间切分**:训练 | 验证 | 测试。训练样本标签周期必须在训练期内结束;验证期选择时,卖出日落在测试期的交易视为未完成 —— 测试期的价格不参与任何选择。
- **一次扫描**:训练完成后逐只股票扫描一遍验证期 + 测试期,记录每个候选信号在每组规则下的收益;选规则和阈值在内存中完成,不必反复读数据。
- **去重**:同一只股票 20 个交易日内只取第一次信号;买不进的信号不占冷却期。
- **组合模拟**:资金 5 份,按信号先后与概率占仓,平仓后复利;收盘价逐日盯市计算最大回撤。
- **报告** `report.md`:目标定义、基准成功率、AUC、验证/测试期准确率与置信下限、各卖出规则对比、按年份与启动类型、卖出原因、组合年化与回撤、评分因子权重、最新交易日市场情绪。

## 7. 内存、性能与异常处理

| 场景 | 处理 |
|---|---|
| 全市场数据量大 | 只为候选启动日建样本,1 字节/特征列式存储;预扫描只保留对齐后的 float 收盘价与状态位(5000 只约 120MB,用完即释放);检验流式进行,只保留高概率候选(`eval.candidateTop`) |
| 内存接近上限 | 每 50 只股票检查一次:超过 `memory.maxUsage` 自动把训练期负样本保留比例减半;再超 8% 停止追加并告警(股票顺序已随机打乱,截断不偏向某个板块) |
| OOM | 捕获后提示调大堆内存或调小 `sample.maxRows`/`gbdt.maxBins`/`threads`,退出码 3 |
| 速度 | 模拟 1500 只 × 3500 日,4 核约 45 秒;全市场约数分钟 |
| 文件损坏/截断/乱序 | 逐条跳过并记录到 `data_warnings.txt` |
| 通达信正在写文件 | 读取失败的文件跳过,不中断 |
| 停牌 | 间隔 > 20 个自然日视为长期停牌,复牌 5 日内不发信号;截面统计中停牌日不计入 |
| 除权 | .day 按"开盘缺口超过跌停幅度"识别除权并前复权(新股前 5 日除外);精确复权请用前复权 txt |
| 新股 | 前 5 日不算涨跌停;上市 120 日内不发信号 |
